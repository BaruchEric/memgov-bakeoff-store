# memgov bake-off store

Throwaway. This repository is the Git/OKF contestant in the memgov Phase 0 bake-off
(see the memgov repo, docs/superpowers/specs/2026-09-12-memgov-bakeoff-design.md).

Every record under memory/ is synthetic seed data about invented people at two invented
tenants. Nothing here is anyone's real memory. The repository is public because required
code-owner review through branch protection is not available on private repositories on
GitHub Free.

Layout: memory/<tenant>/<scope>/<type>/<slug>.md, OKF v0.2 frontmatter.
